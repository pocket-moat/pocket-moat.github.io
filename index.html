Pocket Moat Pipeline

The production tool behind Pocket Moat, a YouTube channel about how companies really make money.

What it does

Pocket Moat Pipeline works only on the Pocket Moat channel's own Google account. With the permissions that account grants, it:

  • uploads finished Pocket Moat videos to the channel as private drafts. A person watches each one and publishes it in YouTube Studio. The tool never publishes anything;
  • reads the channel's own channel and video details, to confirm each upload stayed private;
  • reads the channel's own YouTube Analytics reports, to learn which videos hold viewers' attention.

Who uses it

Only the people who run Pocket Moat. It isn't offered to the public, and it never asks anyone else to sign in.

How it handles data

It reads aggregate channel reports, never information about individual viewers, and nothing it reads is sold or used for advertising. The details are in the privacy policy.
