Privacy policy

Pocket Moat Pipeline · Effective November 18, 2026

What this covers

This policy covers Pocket Moat Pipeline ("the app"), the tool that uploads videos to the Pocket Moat YouTube channel and reads that channel's analytics. The app uses YouTube API Services. Google's own handling of data is covered by the Google Privacy Policy.

What the app accesses

When the channel's Google account signs in, it grants three permissions:

PermissionWhat the app does with it
Upload YouTube videos
youtube.upload		Uploads finished Pocket Moat videos to the channel as private drafts.
View the YouTube account
youtube.readonly		Reads the channel's own channel and video details, for example to confirm an upload is private.
View YouTube Analytics reports
yt-analytics.readonly		Reads the channel's own reports, such as views, watch time and audience retention for each video.

Analytics reports are aggregate. They don't identify individual viewers, and the app collects no personal information about viewers.

How the data is used

Only to run the channel: uploading its videos, checking them, and learning which videos work so the next ones are better. The data isn't used for advertising, isn't sold and isn't used to build a profile of anyone.

Where it's stored

  • The sign-in token is stored as an encrypted secret in GitHub Actions and used only by the channel's own private workflows.
  • Analytics are saved as short summary files in the channel's private GitHub repository.
  • Nothing is stored through these web pages. They set no cookies and run no analytics or ads. GitHub hosts them and Google Fonts serves their fonts; both may keep standard server logs under their own privacy policies.

Who else processes it

Two service providers, only to run the tools described above:

  • GitHub stores the private repository and runs the workflows.
  • Anthropic, whose AI assistant Claude reads the analytics summaries to suggest improvements to future videos.

The data isn't shared with anyone else and isn't used to train generalized AI models.

Limited Use

Pocket Moat Pipeline's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

Access can be removed at any time on the Google Account's third-party access page. Once it's removed, the stored sign-in token stops working and is deleted from GitHub. To have stored analytics summaries deleted, open an issue.

Changes

If this policy changes, the new version is posted on this page with a new effective date.

Contact

Questions about this policy: open an issue on GitHub.
